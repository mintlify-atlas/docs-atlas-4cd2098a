## Overview

Admin endpoints for user management, including listing all users and updating user roles.

<Warning>
  All endpoints on this page require admin role authentication via the `requireAdmin` middleware.
</Warning>

---

## List Users

<api method="GET" endpoint="/api/admin/users" />

Retrieve a paginated list of all users in the system.

### Query Parameters

<ParamField query="page" type="number" default="1">
  Page number for pagination
</ParamField>

<ParamField query="limit" type="number" default="10">
  Number of users per page
</ParamField>

### Response

<ResponseField name="success" type="boolean" required>
  Indicates if the request was successful
</ResponseField>

<ResponseField name="data" type="array" required>
  Array of user objects
  
  <Expandable title="user object">
    <ResponseField name="id" type="string">
      User ID
    </ResponseField>
    
    <ResponseField name="email" type="string">
      User email address
    </ResponseField>
    
    <ResponseField name="name" type="string">
      User full name
    </ResponseField>
    
    <ResponseField name="role" type="string">
      User role: `"user"` or `"admin"`
    </ResponseField>
    
    <ResponseField name="createdAt" type="string">
      ISO 8601 timestamp of account creation
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagination" type="object" required>
  Pagination metadata
  
  <Expandable title="properties">
    <ResponseField name="currentPage" type="number">
      Current page number
    </ResponseField>
    
    <ResponseField name="totalPages" type="number">
      Total number of pages
    </ResponseField>
    
    <ResponseField name="totalItems" type="number">
      Total number of users
    </ResponseField>
    
    <ResponseField name="limit" type="number">
      Items per page
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseExample>
```json Success Response
{
  "success": true,
  "data": [
    {
      "id": "user_123abc",
      "email": "john@example.com",
      "name": "John Doe",
      "role": "user",
      "createdAt": "2024-01-15T10:30:00.000Z"
    },
    {
      "id": "user_456def",
      "email": "admin@example.com",
      "name": "Admin User",
      "role": "admin",
      "createdAt": "2024-01-10T08:00:00.000Z"
    }
  ],
  "pagination": {
    "currentPage": 1,
    "totalPages": 5,
    "totalItems": 50,
    "limit": 10
  }
}
```

```json Error Response
{
  "success": false,
  "message": "Failed to fetch users"
}
```
</ResponseExample>

## Update User Role

<api method="PUT" endpoint="/api/admin/users/:id/role" />

Update a user's role. Admins can promote users to admin or demote admins to regular users.

### Path Parameters

<ParamField path="id" type="string" required>
  User ID to update
</ParamField>

### Request Body

<ParamField body="role" type="string" required>
  New role for the user. Must be either `"user"` or `"admin"`
</ParamField>

### Response

<ResponseField name="success" type="boolean" required>
  Indicates if the role was updated successfully
</ResponseField>

<ResponseField name="message" type="string" required>
  Success or error message
</ResponseField>

<ResponseExample>
```json Success Response
{
  "success": true,
  "message": "User role updated successfully"
}
```

```json Error - Invalid Role
{
  "success": false,
  "message": "Invalid user ID or role"
}
```

```json Error - User Not Found
{
  "success": false,
  "message": "User not found"
}
```

```json Error - Self Update
{
  "success": false,
  "message": "Cannot change your own role"
}
```
</ResponseExample>

## Request Example

```bash cURL
curl -X PUT https://api.example.com/api/admin/users/user_123abc/role \
  -H "Content-Type: application/json" \
  -H "Cookie: session=..." \
  -d '{
    "role": "admin"
  }'
```

```javascript JavaScript
const response = await fetch('/api/admin/users/user_123abc/role', {
  method: 'PUT',
  headers: {
    'Content-Type': 'application/json',
  },
  credentials: 'include',
  body: JSON.stringify({
    role: 'admin'
  })
});

const data = await response.json();
```

## Validation Rules

- Role must be either `"user"` or `"admin"`
- User ID must exist in the database
- Admins cannot change their own role (prevents accidental lockout)
- Returns 400 for validation errors
- Returns 404 if user not found
- Returns 500 for server errors
